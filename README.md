# 下班前 BeforeFive

> 原名 ReportTool（工作回報工具）

工作中隨手記錄，下班前一鍵整理成 `report_YYYY-MM-DD/` 資料夾（含 `report.md` 與附圖），丟給網頁版 Claude / Gemini 寫成 Slack 回報。

所有資料只存在本機，不呼叫任何外部 API。

目前版本：**3.0.0**（主視窗標題列會顯示版本，更新內容見 [CHANGELOG.md](CHANGELOG.md)）。

## 安裝與啟動（Windows）

1. 安裝 Python 3.10 以上
2. 雙擊 `setup.bat`：在 `%LOCALAPPDATA%\ReportTool\venv` 建立虛擬環境並安裝套件（放在 OneDrive 外，避免同步數百 MB 的套件）
3. 雙擊 `run.bat` 啟動（不會出現主控台視窗）

關掉主視窗就會結束程式，不會留在背景執行。全域快捷鍵只在程式開著時有效（主視窗最小化也可以）。重複執行 `run.bat` 只會叫出現有視窗。

**開機自動啟動**：按 `Win+R` 輸入 `shell:startup`，把 `run.bat`（或 `BeforeFive.exe`）的捷徑放進去。

### 打包成 exe

完成上面的 `setup.bat` 後，雙擊 `build.bat`，約一分鐘後產生 `dist\BeforeFive.exe`（單一檔案，約 60 MB，不需要安裝 Python 就能執行）。

- 把 exe 放到任何資料夾都可以；第一次執行會在 exe 旁邊建立 `config\`，`WorkReports\` 也會產生在 exe 旁邊
- 紀錄資料一樣在 `%LOCALAPPDATA%\ReportTool\data`，和 `run.bat` 版本共用同一份
- 單一檔案的 exe 每次啟動要先解壓，大約需要幾秒鐘
- exe 和 `run.bat` 版本不要同時執行（後啟動的會只叫出先啟動的那個視窗）

## 使用方式

| 動作 | 方式 |
|---|---|
| 快速記錄 | 程式開著時，任何地方按 **Ctrl+Alt+R**（可在設定檔修改） |
| 標題 | 內容上方的「標題（可省略）」欄，按 Enter 跳到內容。有標題時，主視窗清單、回報、PPT 和附圖檔名都用標題；追加今日進度與帶入未完成項目會沿用原本的標題 |
| 貼上截圖 | 在文字框按 `Ctrl+V`（例如先用 `Win+Shift+S` 截圖） |
| 加入圖片檔 | 拖曳到視窗，或按「附加圖片…」 |
| 時段 | 狀態列下面的「時段 [起始日期][起始]–[結束日期][結束]」（時間可以打 `09:30` 或 `0930`；日期按箭頭從下拉日曆選，預設是紀錄這一天），以 15 分鐘為一格，打完會四捨五入（`09:07`→`09:00`）。今天的新紀錄兩欄都不填就自動補：起始＝今天前一筆的結束，結束＝存檔當下（沒有前一筆時長就是 0）。補記別天的事、編輯舊紀錄時兩欄都要填；今天的紀錄結束最晚到現在；跨午夜、跨好幾天的工作把結束日期設成後來那天。帶入未完成項目沿用原本的時段（工時統計時同一件工作相同的時段只算一次）；追加今日進度的起訖是當下，需要時再改 |
| 切換狀態 | `Alt+1` 待辦 / `Alt+2` 進行中 / `Alt+3` 等待中 / `Alt+4` 待確認 / `Alt+5` 完成 / `Alt+6` 取消（滑鼠移到按鈕上會顯示快捷鍵；新紀錄預設進行中；取消的紀錄在主視窗會加上刪除線） |
| 優先順序 | 狀態按鈕右邊的「優先」選 1~5（1 最優先，預設 3）。同一層的紀錄依優先順序、再依標題排列，數字 1、2 以紅、橘色標示；追加今日進度與帶入未完成項目會沿用 |
| 選分類 | tag 欄左邊的分類欄：輸入路徑中任何一段文字搜尋（例如打「登入」會找到「開發 › 專案A › 登入頁」），或按 ▾ 從樹狀清單點選；清空就是未分類。每筆紀錄只屬於一個分類（哪一層都可以） |
| 加 tag | 輸入 `#專案A #bug`，會自動補完；下方常用 tag 點一下即可加入或移除。tag 只是補充標籤，不影響分組與排序 |
| 預設值 | 新紀錄會沿用上一筆的分類與 tag，不需要時清掉即可 |
| 儲存 / 取消 | `Ctrl+Enter` / `Esc` |
| 編輯、刪除 | 主視窗雙擊紀錄，或選取後按「編輯」「刪除」（按住 Ctrl／Shift 可以多選一起刪除） |
| 拖曳改分類 | 把右邊清單的紀錄拖到左邊分類樹的分類上放開，就改成那個分類；拖到「未分類」是清除分類。可以先按住 Ctrl／Shift 多選再一起拖 |
| 快速改狀態 | 主視窗在紀錄上按右鍵 →「標記為…」任一狀態 |
| 追加今日進度 | 選取一筆工作（可以是之前的日子）→ 按「追加今日進度」或右鍵選單。新紀錄會串到原本那件工作，視窗上方會列出先前進度，回報中標示「（延續自 MM-DD）」 |
| 預覽與歷程 | 主視窗清單下方的預覽會顯示選取紀錄的完整內容；延續的工作會列出每一天的進度（新的在上面，目前選取的那則加底色）。在紀錄上按右鍵 →「查看歷程…」（或預覽右上角的按鈕）另開視窗，左邊選一則，右邊並排顯示前一則與這一則的完整內容和附圖（不需要前一則時取消勾選「同時顯示前一則」）；下方「◀ 往前一則」「往後一則 ▶」（或 Alt+←／Alt+→）可以一則一則往前、往後看。不需要預覽時取消勾選主視窗上方的「顯示預覽」 |
| 分類樹 | 主視窗左邊是分類樹（分類／子分類，層數不限），每個分類顯示優先度、這一天的紀錄數與時數（都含子分類）、進度條；不需要時數時取消勾選分類樹下方的「顯示時數」。點選分類，右邊只顯示這個分類與子分類的紀錄；最上面「全部」、最下面「未分類」 |
| 分類進度 | 每個分類可以手動填 0～100% 的進度（各層獨立，不會自動計算）：雙擊左邊分類樹的進度欄、在分類上按右鍵，分類樹下方的「設定進度…」，或在「管理分類與標籤」設定。100% 會變成綠色。不需要進度時，取消勾選主視窗上方的「顯示進度」就全部隱藏（已填的進度會保留，回報仍會列出） |
| 分類優先度 | 每個分類可以設定優先度 1～5（1 最優先，預設 3）：在左邊分類樹的分類上按右鍵選「優先度」、雙擊「優」欄，或在「管理分類與標籤」設定。同一層的分類先依優先度、再依手動順序排列，主視窗、回報、PPT 都照這個順序；1、2 以紅、橘色標示 |
| 依分類分組 | 主視窗「依分類分組」打勾時，清單照分類樹分層顯示：每一層先列直接屬於它的紀錄，再列子分類，群組標題有筆數與進度。群組可以收合，取消打勾回到一般清單 |
| 管理分類與標籤 | 主視窗「管理分類與標籤」：分類可新增、新增子分類、改名、設定優先度、設定進度、移動到別的分類底下、排序（拖曳或上移／下移，只在相同優先度之間）、刪除（子分類一起刪，紀錄移到上一層）；tag 可改名、合併（改成已存在的名稱）、刪除 |
| 圖片不給 AI | 取消圖片下方的「給 AI」勾選 |
| 帶入未完成項目 | 主視窗按「帶入未完成項目」：把上一個有紀錄的日子（週一會帶入週五）中未完成（完成、取消以外）的項目複製到今天；不帶圖片，重複按也不會重複帶入 |
| 工作回顧 | 主視窗按「📋 工作回顧」。report.md 的內容會同時複製到剪貼簿，可以直接貼到 AI 網頁 |
| 延續項目的變更 | 帶入或追加進度的工作，report.md 會多一行「⇄ 與 MM-DD 相比：…」，列出狀態、優先、標題、分類、tag 的變化與改動的內容（前：／後：），沒改就寫「沒有變更」。按「📋 工作回顧」時若當天有延續的工作，會跳出比較視窗，左右並排顯示前後內容，刪除的字紅底、新增的字綠底 |
| 範圍整理（週報、月報） | 主視窗按「📅 範圍整理」，選開始與結束日期（或按 本週／上週／本月／上個月），產生 `report_開始_to_結束/`：同一件工作（帶入、追加進度串起來的）只列一次，底下依時間列出每一筆的進展，並寫出最新狀態與合計時數；最後有「## 工時統計」，依分類列出時數與占比。附圖編號連續，內容一樣會複製到剪貼簿。指示沿用 `instructions.md` |
| 搜尋紀錄 | 主視窗下方的搜尋框（`Ctrl+F`）輸入後按 Enter，不限日期找標題、內容、tag、分類；空白分隔多個詞時每個都要出現，`#詞` 只找 tag。結果視窗下方有預覽，雙擊（或 Enter）跳到那一天並選取那筆 |
| 甘特圖 | 主視窗下方按「📈 甘特圖」，選一天（預設是正在看的那天）或一段期間。一天：橫軸是時間，每筆紀錄一條（時長 0 畫成點）；好幾天：每件工作一列，每天畫同一段時間（至少 09:00–18:00，有更早更晚的紀錄就加寬），幾天接起來，長條依實際時間等比例畫、15 分鐘一格。依分類分組、顏色是狀態色，滑鼠移上去看標題與時段，雙擊跳到那筆紀錄；可以換範圍、存成 PNG（預設存到回報資料夾） |
| 匯出 PPT | 主視窗按「📊 匯出 PPT」，產生 `report_日期/report.pptx` |

## 工作回顧產出

```
ReportTool\WorkReports\report_2026-11-02\
├─ 01_修登入頁timeout問題.png   ← 長邊縮到 1600px
├─ 02_timeout修好，已送PR.png
└─ report.md
```

- 紀錄依起始時間排列，每行開頭是時段與時數（`[09:00–10:30 1.5h]`），並標出 `[分類：開發 › 專案A]`；用到的分類會依排列順序列在「## 分類資訊」（附上優先度與進度），AI 會照指示依分類分層整理
- 圖片依紀錄時間排序編號，檔名取紀錄內容的第一行
- md 中用 Markdown 引用寫法 `![附圖1]` 插入圖片，檔名統一列在檔案最後（`[附圖1]: <01_修登入頁timeout問題.png>`）
- 沒勾「給 AI」的圖片不會複製，md 中寫成「（附圖3：未提供）」
- 重新產生時只會覆蓋 `report.md` 和編號圖片，資料夾裡其他檔案不受影響

## 匯出 PPT

- 第 1 頁是封面（日期、各狀態數量、當天用到的分類），之後一則紀錄一頁
- 頁面照分類樹的順序排列（上層的紀錄在子分類之前，未分類放最後），同一個分類內依優先順序、再依標題
- 每頁有時段、狀態、優先順序、分類、tag、延續日期、內容；有附圖時文字在左、圖片在右，標示的附圖編號與 report.md 相同
- 沒勾「給 AI」的圖片不放進投影片，只留「附圖N：未提供」文字
- 每頁的備忘稿放了原始紀錄，AI 美化時可以參考
- 想換樣式：把自己的 .pptx 存成 `config/ppt_template.pptx`，會沿用它的投影片大小與佈景主題（使用其中的「空白」版面配置）

## 設定

都在 `config/` 資料夾（主視窗有「開啟設定資料夾」「編輯 AI 指示」按鈕）：

`config/` 不進版控：第一次執行時會用程式內建的預設值建立，之後的修改（例如 AI 指示中寫到的公司或客戶資訊）只留在本機，不會被 commit。

- `instructions.md`：report.md 中「## 指示」的內容。每次產生時重新讀取，改完不用重開程式
- `settings.json`：
  - `hotkey`：全域快捷鍵，例如 `"Ctrl+Alt+R"`、`"Ctrl+Shift+Space"`、`"Win+F9"`
  - `data_dir`：資料存放位置，空白表示 `%LOCALAPPDATA%\ReportTool\data`
  - `output_dir`：回報資料夾位置，空白表示專案底下的 `WorkReports\`（已加入 .gitignore，不會上傳）
  - `max_image_side`：圖片長邊上限，預設 1600
  - `show_progress`：是否顯示分類進度，由主視窗的「顯示進度」勾選框自動記錄
  - `show_preview`：是否在清單下方顯示預覽，由主視窗的「顯示預覽」勾選框自動記錄
  - `show_hours`：分類樹是否顯示時數，由分類樹下方的「顯示時數」勾選框自動記錄

修改 `settings.json` 後要重開程式。

## 資料儲存

`data_dir` 裡有：

- `reporttool.db`：SQLite，包含 `entries`（紀錄，`start_date`／`start_time`／`end_date`／`end_time` 是起訖時段，`carried_from` 串起同一件工作的歷程）、`categories`（樹狀分類與進度）、`entry_tags`、`tags`（用過的 tag）、`images`、`meta`（裝置 id）
- `images/YYYY-MM-DD/`：原始圖片

歷史紀錄會一直保留；`Database.entries_between(start, end)` 可以直接拿來做週報。

為了之後和手機版同步，每筆紀錄有 uuid 與 UTC 修改時間，刪除的紀錄會留下不含內容的 tombstone。格式規格見 [docs/data-format.md](docs/data-format.md)。

### 備份與匯入

主視窗「備份 ▾」：

- **匯出備份…**：所有紀錄（含圖片）存成一個 zip
- **從備份匯入…**：把 zip 合併進目前的資料。同一筆紀錄以較晚修改的版本為準，所以重複匯入、或在兩台電腦間互相匯入都不會產生重複資料

舊版資料庫會在第一次開啟時自動升級。從 1.x 升級到 2.0 時，原本的分類變成第一層、每筆紀錄的第一個 tag 變成它底下的子分類（tag 本身保留），升級前會先把資料庫備份成同一個資料夾裡的 `reporttool-before-v6.db`。

從 2.x 升級到 3.0 時，每筆紀錄的起訖時段由原本的「時間」（寫下紀錄的時間）推算：結束＝那個時間，起始＝同一天前一筆的時間（每天第一筆時長 0）。推算的時長不一定準，可以再自己修改。升級前會把資料庫備份成 `reporttool-before-v8.db`。

起訖時段以 15 分鐘為一格，存檔時四捨五入（`09:07`→`09:00`）。從 3.0.0 升級時，所有紀錄的起訖會一次取整，升級前備份成 `reporttool-before-v9.db`；時段的起訖日期設成紀錄那天。

備份格式第 4 版加上時段的起訖日期：新版可以匯入舊版的備份，但 3.0 不能匯入新版的備份，要互相同步的電腦請都更新。

3.0 的備份格式是第 3 版：3.0 可以匯入 1.x、2.x 的備份（起訖時段用同樣的規則推算），但舊版不能匯入 3.0 的備份，要互相同步的電腦請都更新到 3.0。

```
%LOCALAPPDATA%\ReportTool\venv\Scripts\python.exe -m pytest
```
