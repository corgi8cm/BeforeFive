# v3.0.0 Roadmap（規劃中）

> 狀態（2026-11-09）：草案，還沒開始做。等 2.0.0（分類樹）合併、發布之後才開始。
> 主題：**時間** —— 記下每件事花了多少時間，以及之後要做什麼、什麼時候要做完。

## 必做

### 1. 紀錄的起始／結束時間（使用者提出）

- 每筆紀錄可以填「起始」「結束」時間，兩個都可以不填
- 現在的「時間」欄位就是起始時間，舊資料不用轉換；只多一個可以空白的結束時間
- 記錄視窗：
  - 新增時起始時間預設是現在
  - 加一個「現在結束」按鈕，按下就把結束時間填成現在
  - 結束時間比起始時間早時不能存
- 主視窗清單顯示 `09:00–10:30（1 小時 30 分）`
- 主視窗右鍵加「結束這項工作」：結束時間填現在，狀態可以順便改成完成
- report.md 的每一行加上時段與時長，範圍整理在最後列出每個分類的總時數
- PPT 每頁顯示時段

### 2. 工時統計

- 左邊分類樹多一欄「時數」，算這一天（含子分類）有填結束時間的紀錄的總時長
- 範圍整理（週報、月報）加「## 工時統計」：依分類樹列出每個分類的時數與百分比
- 時段重疊的紀錄照樣各自計算，不自動扣除；統計旁邊註明這一點

### 3. 搜尋紀錄

- 主視窗加搜尋框，不限日期，找標題、內容、tag、分類
- 結果依日期排列（新的在前），雙擊跳到那一天並選取那筆

## 候選（再決定要不要做）

| 功能 | 說明 |
|---|---|
| 截止日期 | 紀錄可以設截止日；帶入未完成項目時逾期的標成紅色，回報標「（截止 MM-DD）」 |
| 計時器 | 系統匣選單「開始計時／停止」，停止時自動填好起始和結束時間 |
| 日曆瀏覽 | 主視窗日期旁邊可以開一個月曆，有紀錄的日子加點，點了就跳過去 |
| 範圍報告合併延續鏈 | 範圍整理時，同一件工作（同一條延續鏈）只列一次，依時間列出各天的進展 |
| 紀錄範本 | 常用的開頭（例如「站會」「Code review」）一鍵帶入標題、分類、tag |

## 資料格式與相容

- SCHEMA_VERSION 7 → 8：
  - `entries` 新增 `end_time TEXT`（可以是 NULL，格式 `HH:MM`）
  - 跨日的工作不在這版處理：結束時間必須和起始時間同一天
- 備份 bundle 的 FORMAT_VERSION 2 → 3：
  - 紀錄多一個 `end_time` 欄位
  - 讀舊的 2 版 bundle 時沒有這個欄位就當成空白
  - 2.x 的程式讀到 3 版 bundle 要明確拒絕，不能默默丟掉資料
- 要更新的地方：
  - `docs/data-format.md`
  - `tests/golden/` 加一組有時段的資料
  - `instructions.md` 預設內容加一行說明時段與工時統計（用 `OLD_LINES` 自動升級）
